# SKU 批量管理设计

## 目标

新增全量 SKU 管理页，集中维护 SKU 主图、抓取方式和 OWLv2 提示词，并支持批量生成、图片目录导入、事务式重命名和受控删除。

## 入口与视图

- 主界面在“人工批量录入”旁新增“SKU 批量管理”。
- 页面读取全部 `sku_catalog` 行，提供列表与大图卡片两种模式；两种模式编辑同一份本地草稿。
- 列表用于批量核对；大图卡片直接编辑 SKU 名称、提示词、抓取方式和主图。
- 顶部“保存全部修改”统一写入草稿中的新建项、字段修改、主图替换和 SKU 重命名。

## SKU 编辑与新建

- 可编辑字段：`sku`、`owlv2_prompt`、`grasp_method`、SKU 主图。
- 抓取方式只允许 `夹爪` 或 `吸盘`。
- “新建 SKU”只输入名称，立即加入本地草稿；默认抓取方式为 `夹爪`，主图和提示词为空；点击保存后才写入数据库。
- 主图继续存储为 `data/sku_images/<SKU>.png`，由 API 统一解码并规范化为 PNG。

## 批量 OWLv2 提示词生成

- 用户勾选 SKU 后执行“生成并覆盖提示词”。
- 服务端为每个 SKU 取其主图和面积最大的一张正常 ID 图（`expected_sku == actual_sku`）；没有正常 ID 图的 SKU 跳过并报告原因。
- 生成结果覆盖页面草稿中的 `owlv2_prompt`，标记为未保存；只有点击“保存全部修改”才写数据库。
- 生成使用本地 Qwen 的已有提示词生成能力，不改变 DINO 参考图规则。

## 图片文件夹导入

- 页面提供目录路径输入和“导入图片文件夹”按钮。
- API 仅扫描指定目录第一层的 `*.png`，不递归；文件名（不含 `.png`）是 SKU 名称。
- 不存在的名称创建新 SKU，默认抓取方式为 `夹爪`；已存在的 SKU 替换主图，保留提示词和抓取方式。
- 目录不存在、不是目录、无效 SKU 文件名和不可解码图片均逐项报告；有效项可继续导入。

## SKU 重命名

- SKU 名称是主键，重命名由专用数据库操作完成，不能通过普通字段更新实现。
- 操作必须在一个 SQLite 事务中：确认新名称不存在，创建/迁移目录行，更新 `shelf_inventory.expected_sku` 与 `actual_sku` 的全部引用，再删除旧目录行。
- 主图文件同步重命名为 `data/sku_images/<新名称>.png`；文件失败时恢复原文件并拒绝数据库提交。
- `unknown` 是系统保留 SKU，不可改名。

## 批量删除

- 删除前展示所选 SKU、引用的固定货位数量，以及引用将替换为 `unknown` 的提示。
- 确认后在一个 SQLite 事务中，将所有命中的 `expected_sku`、`actual_sku` 更新为 `unknown`，再删除选中的 SKU 目录行。
- `unknown` 自动确保存在，且不可删除、不可改名。
- 数据库提交后删除对应主图文件；无法删除的文件返回警告，不回滚已提交的目录修改。

## 状态与安全

- 当页面有未保存草稿时，目录导入与批量删除必须要求用户先保存或放弃草稿。
- 保存全部修改必须先验证重名、保留 SKU 约束、抓取方式和图片数据，再执行写入。
- 批量生成与图片目录导入不会改变 DINO 的“SKU 主图优先，ID 图回退”规则。

## 验证

- 数据库测试覆盖新建、主图替换、`unknown` 保护、重命名引用迁移及删除引用替换。
- API 测试覆盖文件夹 PNG 导入、批量生成跳过原因和批量删除确认后的结果。
- 前端构建与列表/大图编辑的浏览器检查覆盖两个模式、草稿保存和批量操作提示。
